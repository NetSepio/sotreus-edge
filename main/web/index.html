        Context

        Not an official warning

        These are public feeds. Your phone's emergency alerts and local authorities remain the source for warnings. Overlap in time is not a cause.

        Broadcast by the aircraft

        Each position is what the aircraft's own transponder broadcast, collected by volunteer receivers. Not every aircraft broadcasts, and the list runs up to a minute behind. An aircraft listed at the same time as something else is not linked to it.

        Predicted, not observed

        A satellite predicted overhead means only that its orbit passes over this area at that time. It does not mean the satellite imaged or observed anything here.

            Settings

            Awareness
            LoRa mesh

            Routers and repeaters relay for everyone and should sit somewhere high with steady power. Position beacons send their position more often than other roles.

            Position and telemetry

            The Edge has no GNSS. Each channel sends the position rounded to its precision; channels set to Off never get it.

            Mesh modules

            Also on the Edge: on the LoRa screen, double-press the button to pick one, hold it to send on the primary channel.

            ATAK

            Used in TAK position reports and TAK chat. With the role "TAK position beacon", the Edge reports its position as a TAK position (ATAK plugin v2) instead of a Meshtastic position, so ATAK users see it on their map.

            Remote admin and hardware
            Remote admin is open: any node in radio range can change this Edge's mesh settings, read its configuration and restart it. Add your own node's public key below and choose "Only admin keys".
